# Roadmap

1. **v0.1** (feito): palco, desenho, borracha, timeline, onion skin, play, salvar/abrir, console JS.
2. **Camadas**: várias camadas por frame, visibilidade, ordem, opacidade.
3. **Vetor real**: curvas Bézier editáveis, suavização, pontos de controle, preenchimento.
4. **Timeline avançada**: exposição de desenhos, keyframes, interpolação.
5. **Rig e cutout**: peças, pivôs, hierarquia, deformadores.
6. **Scripting**: API JS estável e Python embutido.
7. **Áudio e exportação**: som, lip-sync, exportar MP4/GIF/sequência PNG.
8. **Interoperabilidade**: importar/exportar formatos abertos.
